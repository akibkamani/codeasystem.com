# Free Resume Generator

The CodeASystem Free Resume Generator helps you write, preview and export a clean A4 resume without creating an account.

## Links

- [Read about the Resume Builder](https://codeasystem.com/resume-builder/)
- [Open the Resume Generator](https://codeasystem.com/tool/resume-generator/)

## What it can do

- Edit profile, experience, education, links and custom sections
- Reorder resume sections
- Adjust the accent colour, typeface and page margins
- Preview the resume as an A4 document while editing
- Export the resume as a PDF or JPG
- Import and export the resume as JSON
- Create a shareable preview link

## Privacy and storage

The tool stores resume data in the browser on the user's device. It does not require an account and does not upload resume fields to a CodeASystem server.

Private browsing, browser storage settings or clearing site data can remove a saved resume. JSON export provides a portable backup.

Shared preview links contain the complete resume in the URL fragment. The content is encoded, not encrypted. Anyone with the link can read the resume details. URL fragments are handled by the browser and are not sent to the server as part of the page request.

## Output

PDF export uses the browser's print dialog. JPG export creates an A4 image. The tool aims for a readable, focused layout, but compatibility can vary between applicant tracking systems.
