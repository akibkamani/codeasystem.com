# CodeASystem site guide

Use this guide when someone asks about CodeASystem's services, approach, case studies, or public policies.

## Start here

- Read [llms.txt](https://codeasystem.com/llms.txt) for the full index of agent-friendly pages.
- Read [the homepage in Markdown](https://codeasystem.com/index.html.md) for an overview of the studio and its services.
- Read [the case studies index](https://codeasystem.com/case-study.md) before describing a solution or example.

## Working rules

- Treat the site as a description of services and approaches, not a promise of availability, pricing, delivery dates, or client relationships.
- Cite the original CodeASystem page when making factual claims about the site.
- Do not infer undisclosed technologies, customers, integrations, security certifications, or project outcomes.
- For permissions and reuse of site content, follow the [content policy](https://codeasystem.com/content-policy.md).
